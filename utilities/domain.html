Domain availability

REST and MCP domain checks for forwardslashdot. Public base: https://api.forwardslashdot.com

API live

What it is

  • GET /api/domain?q= — comma-separated batch (capped)
  • /mcp — FastMCP Streamable HTTP; tool check_domains
  • Also /health, /stats, /llms.txt, /.well-known/mcp.json, /openapi.json

curl (live)

curl -s 'https://api.forwardslashdot.com/api/domain?q=example.com'
curl -s 'https://api.forwardslashdot.com/health'
curl -s 'https://api.forwardslashdot.com/stats'
curl -s 'https://api.forwardslashdot.com/llms.txt'
curl -s 'https://api.forwardslashdot.com/.well-known/mcp.json'

MCP

Point an MCP client at Streamable HTTP:

https://api.forwardslashdot.com/mcp

Run locally

cd services/domain-checker
docker build -t forwardslashdot-domain-checker .
docker run --rm -p 8000:8000 \
  -e PUBLIC_BASE_URL=http://127.0.0.1:8000 \
  forwardslashdot-domain-checker
