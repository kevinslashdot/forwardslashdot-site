Domain availability

REST and MCP domain checks for forwardslashdot. The code is in the repo; a public API host is the next deploy step (Docker / Coolify — separate from this static site).

API not live on www yet

What it is

  • GET /api/domain?q= — comma-separated batch (capped)
  • /mcp — FastMCP Streamable HTTP; tool check_domains
  • Also /health, /llms.txt, /.well-known/mcp.json

Cloudflare Pages hosts only this static site. The FastAPI service needs its own Docker host.

Run locally with Docker

cd services/domain-checker
docker build -t forwardslashdot-domain-checker .
docker run --rm -p 8000:8000 \
  -e PUBLIC_BASE_URL=http://127.0.0.1:8000 \
  forwardslashdot-domain-checker

Or with uvicorn

cd services/domain-checker
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

curl (local today)

curl -s 'http://127.0.0.1:8000/api/domain?q=example.com'
curl -s 'http://127.0.0.1:8000/health'

curl (future public host)

After Coolify (or similar) is up, point these at that HTTPS origin — not at www.forwardslashdot.com (Pages is static-only). 

curl -s 'https://YOUR-API-HOST/api/domain?q=example.com'
curl -s 'https://YOUR-API-HOST/health'
